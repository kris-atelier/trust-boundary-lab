# Trust Boundary Lab

LLM 애플리케이션 보안의 세 가지 설계 원칙을 체험하는 정적 웹 POC입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 빌드 과정이나 패키지 설치가 필요하지 않습니다.

## 데모

1. **프롬프트 인젝션 방어** — 서버 정책, 사용자 요청, 검색 문서를 서로 다른 신뢰 경계로 표현합니다. 악성 문서 지시문은 데이터로 분류하고 답변 근거에서 제외합니다.
2. **에이전트 권한 통제** — 도구 호출 제안과 실행 권한을 분리합니다. 인증된 주체, 역할, 대상 소유권, 승인 기록을 서버가 확인하고 불충족 시 거부합니다.
3. **개인정보 보호** — 브라우저 안에서 이름·전화번호·이메일을 마스킹한 전송 미리보기를 보여주고, 응답 유출 탐지 및 민감값을 제외한 감사 항목을 설명합니다.

## 안전 범위

이 예제는 브라우저에서만 동작하는 개념 증명입니다. 외부 LLM이나 API를 호출하지 않고, 인증·권한 확인·감사 로그를 실제 서버에 구현하지 않습니다. 정규식 기반 마스킹은 예시이며 모든 민감정보를 탐지하지 못합니다. 운영 시스템에서는 서버 측 정책 엔진, 최소 권한 도구, 출력 스키마와 민감정보 검사, 접근 통제된 감사 저장소, 보존 및 삭제 정책이 필요합니다.
